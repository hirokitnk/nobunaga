# 天翔記 ― 戦国群雄伝（非公式ファンリメイク）

『信長の野望・天翔記』（光栄, 1994）に着想を得て、ゼロから作った戦国シミュレーションゲームです。
ブラウザだけで動き、外部ライブラリは使っていません。

> 本作は非公式のファンメイド作品で、株式会社コーエーテクモゲームスとは関係ありません。
> 地図・能力値・家紋の図案・プログラムはすべて独自に作成したもので、原作の画像・音楽・データは含みません。

## 遊び方

いちばん簡単なのは、ビルド済みの単一ファイル `dist/tenshouki.html` をブラウザで開くことです（サーバー不要）。

開発中のソースから動かす場合は静的サーバーが必要です（ES モジュールのため）。

```sh
npm start            # http://localhost:8080 で起動（npx http-server）
npm test             # エンジンのテスト（node --test）
npm run build        # dist/ に単一ファイル版を生成
npm run gen:adjacency  # 城の隣接データを再生成
```

## ゲームの内容

- **シナリオ**：1560年6月、桶狭間の戦いの直後。全国 132 城・48 大名家・約 330 名の武将が登場し、
  史実で後に活躍する武将（伊達政宗、真田幸村、石田三成など）は元服の年になると各家に加わります。
- **月ごとの評定**：各大名家が順番に行動します。武将は1か月に1回だけ命令を実行できます。
  - 内政：開墾（石高）・商業・築城（城防御）・施し（民忠）
  - 軍事：出陣・徴兵・訓練・兵装（足軽／騎馬／鉄砲）・移動・再編
  - 人事：登用・褒美・昇進・追放・**軍団**（城の運営を軍団長に委任）
  - 外交：親善・同盟・停戦・手切れ・降伏勧告
  - 調略：引抜（兵ごと寝返らせる）・流言・扇動
  - 商人：兵糧の売買（秋は米が安い）
- **身分制**：足軽頭 → 侍大将 → 部将 → 家老 → 宿老。勲功を積んで昇進すると率いる兵の上限が増えます。
- **合戦**：17×13 ヘックスの戦術マップ。城門を破って本丸を占領するか、城主（総大将）を倒せば攻略です。
  3日（30ターン）で落とせなければ攻撃側は撤退。地形・兵科・天候（雨は鉄砲不可）・戦法（鼓舞・混乱・火計・突撃）があり、
  攻め手は出陣した城の方角から、守り手の援軍は隣の城の方角から戦場に入ります。委任すればAIが指揮します。
- **戦国の世のできごと**：秋の収穫、台風・疫病・豊作・一揆、寿命による死去と家督相続、捕虜の登用・解放・処断、
  忠誠の低い城主の**謀反**（新しい大名家が興る）、武将の出奔、冬の豪雪地帯からの出陣不可。
- **勝利条件**：他の大名家をすべて滅ぼすか臣従させれば天下統一。
- セーブはブラウザ内（3枠＋自動保存）と、文字列での書き出し／読み込みに対応。

## 構成

```
index.html            開発用エントリー
css/style.css         画面デザイン
src/data/             シナリオデータ（海岸線・城・大名家・武将・隣接）
src/engine/           ゲームエンジン（DOM 非依存。Node でそのまま動く）
  state.js            ゲーム状態の生成・参照・家督相続など
  actions.js          各コマンド
  war.js              出陣・合戦結果・捕虜
  battle.js           ヘックス合戦エンジンと合戦AI
  ai.js               大名AI・軍団AI
  turn.js             月次進行とゲームループ
src/ui/               画面（地図・合戦・ダイアログ・タイトル）
tools/                隣接データ生成・単一ファイル化
test/                 node --test によるテスト
```

城の隣接関係は、簡略化した海岸線の上で城を母点とするボロノイ分割を行い、陸で接するものを自動で結んでいます
（`tools/gen-adjacency.mjs`）。海峡を挟む航路と、険しい山越えの除外は `src/data/castles.js` で指定します。

武将の能力値は本作独自の評価です。史実上の生没年をもとにした「寿命」を持ちますが、戦死・横死した武将は
ゲーム上の寿命を延ばしてあります。
